This project is a simple web application built with the Flask framework in Python. It allows users to upload a PDF file through a web interface, specify a starting and ending page number, and then split the PDF to extract only those pages. The core PDF manipulation is handled by the PyPDF2 library in the pdfsplitter.py file, while app.py manages the web server, routes, file handling, and interaction with the HTML templates. The templates provide the user interface for uploading, confirming the split range, and downloading the resulting cropped PDF file.
